What this Terraform would cost before anyone runs apply

Three Terraform blueprints: an AWS EKS cluster with GPU nodes, a GCP Vertex AI endpoint with BigQuery, and an Azure AKS cluster with Cosmos DB. Every morning a GitHub Actions job parses the .tf files, prices each resource, checks the guardrail it should enforce and totals the bill in DuckDB.

    03

    Method

    What the numbers are and aren't.

    Parsing
    A Python script reads every resource block in terraform/aws, terraform/gcp and terraform/azure. Nothing is planned or applied.
    Prices
    Each resource type maps to a monthly list-price estimate for the size in the blueprint, at on-demand rates. Real bills move with usage, region and discounts, so read these as a sizing guide.
    Guardrails
    Each priced resource lists the security control its blueprint is written to enforce, such as KMS encryption, IMDSv2 or a private endpoint.
    Pipeline
    GitHub Actions cron (06:00 UTC) → Python HCL parse → DuckDB totals → JSON → GitHub Pages
